# Dataset Licenses

This document outlines the licensing and usage constraints for the datasets used in the RetinaViT project. The datasets are used strictly for non-commercial, research-only purposes.

## APTOS 2019 Blindness Detection
- **Source**: [Kaggle](https://www.kaggle.com/c/aptos2019-blindness-detection/data)
- **License**: Competitor Data Use Agreement (Research Only).
- **Constraints**: Use is limited to the competition and related research. Redistribution of the raw data is not permitted. Please refer to the official competition rules for details.

## MESSIDOR-2
- **Source**: [ADCIS / Messidor](https://www.adcis.net/en/third-party-programs/messidor/)
- **License**: Creative Commons Attribution-NonCommercial-NoDerivs 4.0 International (CC BY-NC-ND 4.0).
- **Constraints**: Research only. No commercial use is allowed. Proper attribution to the Messidor-2 partners and relevant publications is required.

## IDRiD (Indian Diabetic Retinopathy Image Dataset)
- **Source**: [IDRiD Grand Challenge](https://idrid.grand-challenge.org/)
- **License**: Creative Commons Attribution 4.0 International (CC BY 4.0), or similar research-only license depending on the specific source (e.g., IEEE Dataport).
- **Constraints**: Use for benchmarking and research. Provide proper citation of the original IDRiD paper.
