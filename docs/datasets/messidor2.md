# MESSIDOR-2

## Source
- **Website**: [MESSIDOR-2 / ADCIS](https://www.adcis.net/en/third-party-programs/messidor/)

## Instructions
1. **Request Access**: Visit the ADCIS website and follow the registration instructions to request the MESSIDOR-2 dataset.
2. **Download**: Once access is granted, download the images and the CSV with scores (e.g., `messidor_data.csv`).
3. **Placement**: Unzip and place images into `datasets/raw/messidor2/IMAGES/` and the scores file into `datasets/raw/messidor2/`.

## Expected Structure
```text
datasets/raw/messidor2/
├── IMAGES/
│   ├── ... .tif
└── messidor_data.csv
```
