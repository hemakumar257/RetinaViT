# Contributing

Thank you for contributing to RetinaViT. Please follow these guidelines:

- Fork the repo and create a branch with the `feature/` prefix for new features.
- Write tests for new functionality and ensure `pytest` passes.
- Run `black` and `isort` before opening a PR.
- Keep data with PHI out of git (see project policy in docs/git_workflow.md).

We welcome RFC-style issues for larger design changes.
