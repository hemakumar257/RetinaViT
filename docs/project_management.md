# Project Management

## GitHub Project Board
We use a GitHub Project board to track progress. The board should have the following columns:
- **Backlog**: Tasks planned for the future.
- **In Progress**: Tasks currently being worked on.
- **Review**: Tasks waiting for technical or clinical review.
- **Done**: Completed tasks.

## Labels
- **type:bug**: Something is broken.
- **type:feature**: New functionality.
- **type:docs**: Documentation only.
- **phase:X**: Denotes which phase of the roadmap the task belongs to (e.g., `phase:1`).

## Linking Issues
Always link issues to the Project Board and assign them to the relevant phase label to maintain visibility.
